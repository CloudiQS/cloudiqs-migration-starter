# Evidence Index — Where to Look

> **This is a map, not a summary.** It names which file and which heading to
> open; it never says what the section establishes, because deciding that — and
> whether it covers this customer — is the work. A map that pre-answers produces
> citations drawn from the map instead of the source.

**Layer table** — what a citation from each document type can settle:

| Filename pattern | Layer | Can settle | Cannot settle |
|---|---|---|---|
| <exec brief / 1-pager> | Applicability | Whether the pattern is worth considering; target profile; outcome ambitions | Anything technical; headline numbers are targets |
| <design doc / SDD> | Architecture | Principles, constraints, anti-claims | Step-level method or acceptance criteria |
| <runbook / implementation guide> | Delivery | Prerequisites, phases, validation, success criteria | Applicability to sources it wasn't written for |
